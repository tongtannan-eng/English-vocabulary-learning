# 首屏加载优化

2026-10-30：使用相同 Vite 生产构建，对入口的静态 JavaScript 依赖求和。优化前单入口 1067.95 KB，逐文件 gzip 估算 338.61 KB；当前入口及静态依赖合计 723.97 KB，gzip 估算 235.59 KB，分别减少约 32.2% / 30.4%。当前包含 10 个初始静态块、13 个延迟入口。

## 加载边界

- 单词卡首页直接加载；编辑、设置、练习中心、复习、记录、生词、错题、每周和回收站页面进入时加载。
- 首页筛选面板展开后才加载日期与状态筛选组件；超过 20 组才加载分页组件；请求删除时才加载确认弹窗。
- 共享控件由构建工具自动拆分并复用，不手工把整个 Ant Design 放入首屏公共包。加载中有状态提示，页面加载失败可刷新重试。
- 字典仍沿用原有读取机制，不在本次改动中预载。

## 复查

运行 `npm run build` 后运行 `npm run report:bundle`。脚本读取 `dist/.vite/manifest.json`，从构建入口递归跟踪 `imports`，按文件去重，统计 JavaScript 原始字节及逐文件 gzip 大小；不把 `dynamicImports` 当作初始依赖。

这些数值是构建体积，不包含 CSS、学习数据、字体、字典，也不代表所有路由最终下载的总量。若首页筛选状态为展开，或有超过 20 组卡片，会立即请求对应延迟组件。后续构建会因代码或依赖变化而波动，不能用入口单文件大小代替全部初始依赖。未测量真实网络加载时长或低端设备性能。
