## 上一轮第 6 项建议（本轮已实施）

1. **编辑页的行内信息密度，优先级高。** 每行都占一整行展示「常用搭配与个人备注」入口，有重复词时又叠加来源说明。建议把附加字段入口移到行头、显示内容数量，重复来源默认只显示简短摘要，按需展开详情；主视线留给英文和释义。保留全量校验、草稿与跨页定位。
2. **桌面复习工具栏，优先级中。** 主题、模式、顺序、重开和说明同时铺开，且与偏好页存在重复入口。建议桌面也提供可收起的「本轮设置」，常显当前模式/顺序，重开动作旁明确说明会重置本轮；手机已有折叠方式可复用。
3. **学习记录的解释层级，优先级中。** 表格日期较长，统计口径与复习排期说明集中在底部长段文字。建议日期简写、保留完整日期提示，把「不同词条」「首次提交」解释收进可展开的统计说明，先展示成绩，再让用户按需阅读口径。
4. **样式维护，优先级中。** `src/styles/index.css` 已超过 1300 行，同一组件和媒体查询存在分散覆盖。建议按导航、编辑、复习、设置等职责拆分样式，并合并重复断点；以两种主题、320px/375px 和桌面截图作为整理基准。这是维护优化，当前无需为了拆分改变产品行为。

上述为上一轮建议；2026-10-30 已按本次需求实施这四项。
