# 数据备份和恢复

「偏好与数据 → 备份与恢复」中的「导出全部数据」生成 v5 JSON，范围覆盖当前应用保存的用户数据：所有日期的单词卡、各词的释义/搭配/备注/生词状态与排期、真实作答记录、未完成队列的实际顺序/位置/模式/输入、包括不完整行和单词行删除撤销记录的新建/修改草稿，历史错题快照、回收站（含附带的草稿和队列）、最近完整导出记录，以及主题、发音、复习偏好、首页模块折叠、列表筛选/分页/月折叠/预览/滚动位置。

数据按当前浏览器站点隔离。备份文件可在其他设备或浏览器导入；应用代码、内置字典、系统语音包和浏览器权限不属于用户备份数据。尚未写入的数据及浏览器自身状态（例如鼠标位置、焦点或滚动动画）不随文件迁移。

## 通过 GitHub 在电脑间同步

1. 每次开始学习前，在项目目录执行 `git pull`，然后在「偏好与数据」选择「导入 Git 同步文件」。首次同步且文件尚不存在时，跳过导入。
2. 学习结束后，在同一页面选择「导出 Git 同步文件」，自动写入项目 `sync/english-sync.json`。文件已变化时需要先导入，避免直接覆盖更新。
3. 检查 `git status` 和变更内容，提交 `sync/english-sync.json` 并推送；另一台电脑重复第 1 步。

这是手动同步，应用不会执行 Git 命令。请避免多台电脑同时离线修改后分别覆盖同一文件：Git 可能产生冲突，而相同单词卡的并发修改在导入时按整组更新时间选择较新的版本，并不会逐字段合并。发生冲突时保留两份文件，逐一导入并检查后重新导出，不要直接手工合并 JSON。

自动读写只在本机通过 `npm run dev` 或 `npm run preview` 启动的项目中可用，静态托管页面无法访问项目目录。启动服务后如果修改了 Vite 配置，请重启服务。

同步文件包含学习记录、草稿和偏好；提交前确认仓库的可见性。Git 历史也会保留旧版本，后续删除文件不等于删除历史中的数据。个人数据建议使用私有仓库。

## 导入行为

- 接受原有 v1 单词卡备份、v2 学习记录备份，v3、v4 及 v5 完整备份或单组备份。
- 先验证结构；格式有误时取消整次导入。旧文件缺少的新字段不会用空值覆盖本地设置。
- 回收站条目的删除时间参与合并；旧备份里尚未删除的词组，不会覆盖本地较新的删除操作。恢复后的更新版本也不会被旧删除记录覆盖。
- 默认合并：保留本地较新的同 ID 单词卡、草稿和复习进度；学习记录按 ID 去重。不删除本地其他词组或记录。
- 完整备份会恢复文件中的主题、发音、复习偏好与页面状态，并立即刷新当前界面；旧版及单组备份不更改这些设置。
- 单词正文已被较新本地版本修改、或词已删除时，相应的失效队列会被校验并移除，避免恢复成错误题目；旧草稿正文冲突仍由编辑页提示处理。
- 设置和草稿写入后才提交学习状态；任何写入失败会尝试恢复本次写入前的各项值。若浏览器连回滚也拒绝，会明确提示部分回滚失败，不把结果显示为成功。

「导入」是合并恢复，不是整站覆盖或清空重置。重复导入不会重复增加同一条学习记录。

## 单组导出

单词卡更多菜单的「导出这组」包含该组全部单词字段、相关历史记录、该组编辑草稿，以及只引用所选词组、可以独立恢复的未完成队列。跨词组的整周或今日队列不会截断后伪装成完整队列；新建草稿和全局设置仅在顶部完整备份中导出。

仅需转移某一组时使用单组导出；迁移设备或保护全部学习数据时使用「导出全部数据」。

## 备份状态提示

「偏好与数据 → 备份与恢复」显示最近一次完整导出的时间，并比较当前数据与该次导出：新增、修改、移除的单词行，新增作答记录，以及词组、草稿、进度、回收站或设置的变化。行数按词组中的实际单词行计算，与学习记录中的去重词条数是不同口径。

完整导出生成文件后才更新记录；单组导出不更新完整基线。页面导航、列表筛选及滚动本身不触发重复提醒，但仍随完整备份保存。导入带有较新导出记录的文件后会标注“来自导入备份”，不会冒充本机新下载。浏览器无法确认文件最终是否保存，因此时间标为“最近完整导出”，请确认下载文件已保留。

回收站默认不自动清空，正常删除可以撤销或稍后恢复。永久删除会再次确认，只移除该条回收站内容，不伪造或删改真实学习成绩。

## 历史错题

历史错题来自真实“不认识”标记、已有作答记录和旧数据当前的生词状态。后续标记认识、修改或删除原词条，都不会删除已保留的历史快照；未知的旧时间显示为未记录，不补造作答成绩。相同英文和释义合并展示，来源分别保留。

v5 完整备份包含所有历史快照，单组备份只包含该组来源。导入合并、去重并保留较新的不认识时间；v1–v4 缺少该字段时仍保留本地历史，并从旧文件实际保留的数据恢复可查到的历史。

## 拼写错题与语速兼容

新的拼写记录保存原始输入 `answer`，错题本从真实记录聚合，不额外保存容易失步的计数。完整备份包含这些输入及 `errors:chinese` / `errors:dictation` 未完成队列；单组导出仅保留对应范围。首次成绩与原记录 ID 保持不变。旧记录缺少输入时保留原成绩，展示“具体拼写未记录”，不会猜测当时的输入。

v5 的 `preferences.speechRate` 是可选字段，仅接受 0.7 / 0.9 / 1.1。新完整备份保存并恢复语速；旧 v5 或更早文件缺失此字段时保留本机语速，首次使用默认 0.9。无效语速会导致导入校验失败，不会部分导入。
