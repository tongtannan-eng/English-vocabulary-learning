# 每日单词

按天记录单词，使用翻卡、拼写、生词重练和每周复习巩固记忆。数据保存在浏览器 localStorage，不需要账号和后端。

## 开发

```bash
npm install
npm run dev
```

## 功能

- 中文释义候选点击输入框展开，悬停不展开；其他下拉控件（主题、发音、更多、筛选、日期）仍在桌面端悬停展开，移入弹层保持展开，键盘和触屏兼容
- 黑白 / 活力两种主题，顶部和复习页均可切换，本机自动记住选择，同一站点的多个标签页同步；任务、学习成果和列表表头有明确的视觉层次
- 顶部统一「学习首页 / 练习中心 / 偏好与数据」导航；首页聚焦今日任务和单词卡，短时/每周/生词/记录集中在练习中心，备份与回收站位于偏好与数据页
- 今日任务及搜索筛选可折叠并记住状态，收起时仍展示数量与快捷入口
- 偏好与数据页可设置全局主题、发音口音、默认复习模式和顺序，自动保存并随完整备份迁移；新练习使用默认值，续接练习保留原有模式、顺序和输入
- 按钮统一扁平样式，无阴影、不额外加粗；活力主题使用柔和浅绿背景和边框，编辑底部操作栏使用实色背景隔开单词列表
- 新建、修改某一天的单词卡；删除会移入回收站，支持立即撤销、恢复和确认后永久删除，回收站不自动清空
- 批量粘贴支持 Excel TSV、CSV、英文＋释义多行文本，预览可编辑与选择行，重复词提醒并允许不同词义，单次最多 500 行
- 单词卡按月分组并倒序显示，紧凑行支持展开预览；编辑常显，悬停更多菜单可单组导出和删除，触屏也可点击打开；未命名单词卡的名称留空
- 支持全量搜索名称、英文、中文，并按学习日期和生词状态筛选；默认每页 20 组，复习返回后恢复筛选、页码、月份折叠和滚动位置
- 每个单词包含英文和中文释义，可选填写多条常用搭配或例句、个人备注
- 新建和修改时提醒当前词组及历史词组里的重复词，并显示来源，允许保留不同词义
- 长单词卡编辑每页 10 行，支持查找英文、释义、搭配和备注、只看未填完整；添加后自动定位，固定操作栏随时添加或保存；保存校验覆盖全部页面
- 编辑页删除单词行支持连续撤销，恢复原位置、释义、搭配和备注；未保存的撤销栈随草稿及完整备份保留，保存单词卡后结束本次撤销
- 释义候选根据可用空间向上/向下展开，避开编辑工具栏和底部操作栏；方向键移动、Enter 选择、Escape 关闭，词库请求失败可直接重试
- 复习已有作答、翻面或输入时，重新开始/切换顺序需确认；取消保留原进度，确认后仍保留真实记录与排期
- 编辑草稿自动保存，刷新、离开再返回时可继续；旧草稿遇到正文更新时由用户选择恢复或放弃
- 复习时翻面选择「认识 / 不认识」，第一轮结束后自动重练不认识的词一遍
- 历史错题本永久保留曾标记“不认识”的词，后来认识不移除；同英文同释义合并展示，可搜索、按状态筛选和再次复习，原词条删除或修改后保留快照
- 生词本记录未掌握的词；选择「认识」后自动移出，刷新后保留状态
- 正面可以在英文和中文之间切换
- 中文正面可输入英文自测，提交后标出多写、漏写和拼错的部分；忽略大小写和首尾空格
- 编辑行头展示搭配数量和备注状态，附加字段与重复来源按需展开，保留全部内容、草稿和跨页校验
- 桌面与手机复习页默认收起「本轮设置」，常显模式和顺序；展开设置不重置进度
- 听写模式先播放英文发音再输入，提交前隐藏英文、中文和包含答案的朗读按钮标签
- 练习中心新增「拼写错题」：保留实际错误输入、差异对照和错答次数，分别重练中文拼写与听写，支持中途续接；只收录首轮独立错答，纠正后仍可回看，旧记录缺失的具体输入不补造
- 未完成复习自动保存实际随机词序、位置、模式和输入内容，首页可继续；完成后清除续接状态
- 可以按顺序复习，也可以随机复习
- 每周复习按周一至周日汇总，支持按日期顺序或打乱整周所有词，并可查看其他周
- 朗读支持美式、英式、澳式发音并记住选择，排除系统音效声音；需要设备安装对应英语语音
- 全局语速提供慢速 0.7×、常速 0.9×、稍快 1.1×；沿用原 0.9 默认值，应用于所有朗读、听写和试听，跨标签页同步并随完整备份迁移
- 短时练习提供 5 / 10 / 20 词入口，优先到期词、同义词条去重，支持断点恢复；不足目标数时只练现有词，生词额外重练一遍
- 今日任务汇总到期、逾期和新词；按顺序时先旧后新，未来学习日期的单词不提前安排
- 复习间隔按 1、3、7、14、30、60 天递进，同日重复不加速；忘记或首次拼写未通过的词次日再练
- 学习记录展示最近七天的去重词条、自评结果、首次拼写和首次听写成绩，重复、看过答案和重练不会虚增首次正确率
- v5 完整 JSON 备份包含所有词组、搭配、备注、生词状态、排期、学习记录、草稿、未完成复习、历史错题、回收站、完整导出记录、主题/发音/复习偏好、折叠/筛选/列表状态；兼容 v1/v2/v3/v4。导入合并并保留较新本地内容，写入失败会尝试回滚。单组导出仅包含该组相关数据与可完整恢复的队列，不修改全局设置
- 备份状态展示最近完整导出时间、新增单词行与作答记录、修改和移除等变化；仅完整导出更新基线，单组导出不算完整备份，导航滚动本身不会反复提醒

快捷键：空格翻面，1 不认识，2 认识，左方向键回到上一张，右方向键查看答案或前进到已评价的下一张。拼写输入框按 Enter 提交；输入时不触发复习快捷键。

## 加载与样式

首页保留直接加载，其他页面按路由加载；筛选面板、多页分页及删除确认弹窗仅在需要时加载。页面加载失败可刷新重试。`src/styles/index.css` 只汇总入口，样式按基础、导航、单词卡、编辑、学习、设置、主题和响应式拆分；共享颜色仍使用语义变量。

本次构建的首屏静态依赖 JavaScript 从 1067.95 KB 降至 723.97 KB，约减少 32%；逐文件 gzip 估算从 338.61 KB 降至 235.59 KB。此处是构建体积比较，不是实际加载耗时测试。构建后运行 `npm run report:bundle` 可复查，口径见 [加载优化说明](docs/performance.md)。

## AI 开发约定

共享规范维护在 [AGENTS.md](AGENTS.md)，已配置 Cursor、Codex、Claude Code、GitHub Copilot、Gemini CLI 和 Windsurf / Cascade 的项目规则入口。开发时需遵守中文释义点击、其他下拉 hover、主题、数据保护和验证约定。

修改共享规则后运行：

```bash
npm run rules:sync
npm run rules:check
```

`npm run lint` 会检查规则入口一致性和菜单组件约束。各工具入口由脚本生成或原生导入共享规则，使用方式、加载确认和限制见 [AI 开发说明](docs/ai-development.md)。

## 源码结构

- `src/app/`：应用状态编排与路由
- `src/features/decks/`：单词卡列表、编辑、查找、重复提醒及释义候选
- `src/features/study/`：复习、拼写、听写、排期、学习记录和朗读
- `src/features/settings/`：全局习惯设置、完整备份/恢复及回收站入口
- `src/services/`：本地存储、草稿、完整备份与偏好
- `src/shared/`：通用组件、hover hook、主题、类型及日期工具
- `src/styles/`：全站样式

测试与对应业务模块放在一起。目录职责见 [源码说明](src/README.md)，备份范围与恢复方式见 [备份说明](docs/data-backup.md)。
