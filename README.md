# 每日单词

按天记录单词，通过翻卡、拼写、听写和定期复习巩固记忆。数据保存在当前浏览器，无需账号或后端。

## 开发

```bash
npm install
npm run dev
```

## 功能

### 主要功能

#### 单词卡、词组与语句

- **记录和管理单词卡**：按天新建、编辑，填写英文、中文释义，以及可选的搭配、例句和备注；列表按月分组，支持预览和朗读。
- **管理词组和语句**：单独记录英文和中文，随时添加、修改或删除。
- **查找和批量录入**：按名称、英文、中文、日期或生词状态查找单词卡；支持粘贴 Excel、CSV 和多行文本，录入时提示重复词。

#### 复习与练习

- **选择适合的模式**：通过英文翻卡、看中文拼写或听写练习，支持顺序和随机顺序；可在复习时补充例句和备注。
- **今日任务和短时练习**：根据新词与到期情况安排复习；短时练习可选择 5、10 或 20 个单词。
- **每周、每月和随机复习**：按周或月回顾单词；随机复习可选择单词、词组或语句，每轮结束后可继续复习其他内容。
- **生词与错题**：首轮不认识的单词会加入生词本，并在本轮结束前再练一遍；重练无需再次评分，之后可在生词本继续复习。历史错题和拼写错题可单独回看和练习。
- **记录进度**：未完成的复习保留词序、位置、模式和输入；学习记录展示最近七天的练习情况和首次成绩。

#### 数据与多设备

- **本地保存**：单词、学习记录、草稿和偏好保存在当前浏览器，刷新后仍可使用。
- **备份与恢复**：支持导出完整备份、导出单组单词卡，以及导入备份；删除的单词卡可在回收站恢复。
- **数据概览与备份提醒**：查看本机各类学习数据数量和最近完整备份；可选择每周、每月或关闭提醒，数据变化较多时也会提示备份。
- **多台电脑同步**：通过固定的 Git 同步文件配合 GitHub 手动同步，完整步骤见下方[多台电脑同步](#通过-github-在多台电脑之间同步)。

### 辅助功能

#### 编辑与查找

- 长单词卡每页编辑 10 行，支持搜索、筛选未完成行和跨页保存；删除单词行后可以撤销。编辑草稿自动保存，遇到正文更新时可选择恢复或放弃。
- 批量录入最多 500 行，支持预览、编辑和选择；重复提醒会显示来源，允许保留不同词义。
- 列表支持筛选、分页和月份折叠，返回后恢复筛选、页码、展开状态和滚动位置。今日任务和搜索筛选区域也可折叠。
- 中文释义可手动填写或从候选中选择，支持方向键、Enter 和 Escape；词库请求失败时可重试。

#### 学习习惯与偏好

- **复习排期**按 1、3、7、14、30、60 天递进；同日重复练习不加速，忘记或首次拼写未通过的词次日再练。短时练习优先选择到期词并去重。
- **发音与语速**支持美式、英式、澳式口音，以及慢速、常速和稍快语速；口音和语速会记住选择，设备需安装对应的英语语音。
- **主题与复习偏好**可设置黑白或活力主题、默认复习模式和顺序。未完成练习继续使用原来的模式、顺序和输入。
- **学习记录**按词条去重，分别统计自评、首次拼写和首次听写；看过答案、重复练习和生词重练不会虚增首次正确率。
- **拼写错题**保留实际错误输入和差异，按中文拼写与听写分别重练；历史错题保留原词条快照，后续认识或删除原词条也可回看。

#### 数据保护与交互

- 完整备份包含学习数据、排期、未完成复习、草稿、回收站和偏好等，并兼容 v1–v4 备份；单组导出不包含全局设置。备份状态显示最近完整导出及此后的数据变化。详见[数据备份和恢复](docs/data-backup.md)。
- 编辑和复习支持快捷键；复习快捷键可在「偏好与数据」中自定义。编辑区默认使用 Command/Ctrl + Enter 保存、Esc 取消；单词卡还支持 Alt + N 添加行和 Command/Ctrl + D 删除当前行。
- 中文释义候选点击输入框展开；其他下拉控件在桌面端悬停展开，并支持键盘操作和触屏使用。

## 通过 GitHub 在多台电脑之间同步

学习数据保存在各自浏览器中，不会随代码自动同步。每台电脑需要先克隆同一个 GitHub 仓库、安装依赖并在本机运行应用；Git 同步文件固定为 `sync/english-sync.json`。

每次切换电脑时，按以下顺序操作：

「偏好与数据 → 备份与同步」也提供步骤指引和本地同步文件状态；GitHub 的拉取和推送状态仍需自行确认。

1. **拉取 GitHub 更新**：在项目目录执行 `git pull`。
2. **导入数据**：打开「偏好与数据 → 备份与恢复」，点击「导入 Git 同步文件」。应用会读取项目中的同步文件并合并到当前浏览器。
3. **学习**：正常使用应用，数据保存在当前浏览器。
4. **导出数据**：学习结束后，在同一页面点击「导出 Git 同步文件」，应用会更新 `sync/english-sync.json`，无需选择路径。
5. **提交并推送 GitHub**：在项目目录检查变更，确认暂存内容后提交同步文件并推送：

   ```bash
   git status
   git add sync/english-sync.json
   git diff --cached
   git commit -m "更新学习数据"
   git push
   ```

   提交会包含所有已暂存的文件，请在 `git diff --cached` 中确认没有其他不想提交的改动。

首次同步时，如果仓库里还没有 `sync/english-sync.json`，请在已有学习数据的电脑上先导出，再提交推送；其他电脑拉取后即可导入。拉取、提交和推送需要手动执行，应用不会自动操作 Git。

同步文件在上次导入或导出后发生变化时，应用会要求先导入再导出，避免直接覆盖。尽量避免多台电脑同时离线修改：同一单词卡的并发修改按整组更新时间合并，不会逐字段合并。同步文件包含学习记录、草稿和偏好，请确认 GitHub 仓库的可见性；Git 历史也会保留旧版本。

自动读写同步文件需要通过本地项目运行 `npm run dev` 或 `npm run preview`；静态托管页面不能访问项目目录。更多说明和冲突处理见 [数据备份和恢复](docs/data-backup.md)。

## 加载与样式

首页保留直接加载，其他页面按路由加载；筛选面板、多页分页及删除确认弹窗仅在需要时加载。页面加载失败可刷新重试。`src/styles/index.css` 只汇总入口，样式按基础、导航、单词卡、编辑、学习、设置、主题和响应式拆分；共享颜色仍使用语义变量。

本次构建的首屏静态依赖 JavaScript 从 1067.95 KB 降至 723.97 KB，约减少 32%；逐文件 gzip 估算从 338.61 KB 降至 235.59 KB。此处是构建体积比较，不是实际加载耗时测试。构建后运行 `npm run report:bundle` 可复查，口径见 [加载优化说明](docs/performance.md)。

## AI 开发约定

共享规范维护在 [AGENTS.md](AGENTS.md)，已配置 Cursor、Codex、Claude Code、GitHub Copilot、Gemini CLI 和 Windsurf / Cascade 的项目规则入口。开发时需遵守中文释义点击、其他下拉 hover、主题、数据保护和验证约定。

修改共享规则后运行：

```bash
npm run rules:sync
npm run rules:check
```

`npm run lint` 会检查规则入口一致性和菜单组件约束。各工具入口由脚本生成或原生导入共享规则，使用方式、加载确认和限制见 [AI 开发说明](docs/ai-development.md)。

## 源码结构

- `src/app/`：应用状态编排与路由
- `src/features/decks/`：单词卡列表、编辑、查找、重复提醒及释义候选
- `src/features/study/`：复习、拼写、听写、排期、学习记录和朗读
- `src/features/settings/`：全局习惯设置、完整备份/恢复及回收站入口
- `src/services/`：本地存储、草稿、完整备份与偏好
- `src/shared/`：通用组件、hover hook、主题、类型及日期工具
- `src/styles/`：全站样式

测试与对应业务模块放在一起。目录职责见 [源码说明](src/README.md)，备份范围与恢复方式见 [备份说明](docs/data-backup.md)。
